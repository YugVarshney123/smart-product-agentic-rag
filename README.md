# Smart Product Agentic RAG

An AI-powered Smart Shopping Assistant for visually impaired and elderly users.

## Features

- OCR Product Reading
- AI Information Extraction
- PostgreSQL Product Knowledge Base
- FAISS Vector Search
- Retrieval-Augmented Generation (RAG)
- Voice Output
- Admin Dashboard
- Inventory Management
- Product Scanner
- JWT Authentication
- Stock Monitoring
- Expiry Detection

---

## Tech Stack

### Frontend

- React
- Vite
- Axios

### Backend

- FastAPI
- SQLAlchemy
- PostgreSQL
- FAISS
- Sentence Transformers
- EasyOCR
- Tesseract OCR
- pyttsx3

---

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
